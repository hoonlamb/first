# Korean copy: Toss writing principles first

## Precedence

- **Korean surface** (문체, 어휘, 문장 길이, 문장부호, 톤): this skill wins over every other skill.
- **Strategy and structure** (what to say, in what order, positioning, CRO checks): `copywriting`, `cro`, `product-marketing` win.

## Process

1. Do not translate English sentence by sentence. Extract the message (who, what outcome, what action), then write it in Korean from scratch.
2. Apply the rules below.
3. Read the result as the user would on a phone: one idea per line, no word that can be cut.

## Rules

Source status: summarized from search-engine excerpts of Toss's public writing guides. The original pages (toss.tech, developers-apps-in-toss.toss.im) could not be opened when this file was written. Verify against them before treating any line as final.

**Core values (5):** Clear 명확한, Concise 간결한, Casual 친근한, Respect 존중하는, Emotional 공감하는.

| Rule | Detail |
|---|---|
| 해요체 | Use 해요체 in all copy, regardless of context. |
| 능동형 | Prefer active sentences. Use passive only in specific situations. |
| 한 줄로 말하기 | Say it in one line. Cut words that carry no meaning (Toss: "Weed cutting"). |
| 긍정형 | Prefer "~하면 할 수 있어요" over "안 돼요, 없어요". Negative form is acceptable when it reassures, such as data-collection notices. |
| 다음 흐름 힌트 | Let the reader predict what happens next (Toss: "Predictable hint"). |
| 이모지 | At most one icon or emoji at a time. Never several in a row. |
| 느낌표·물음표 | Avoid them by default. Use them when inviting participation. |

Consequence for other skills: `copywriting` suggests rhetorical questions. In Korean, apply the punctuation rule above and prefer a plain statement.
