# 댕큐 출시 영상 (28.6초, 1920×1080, 30fps, H.264, 무음)

파일: `dangq-launch-1080p.mp4` (사이트에서는 `app/public/media/`의 사본을 씀), 포스터 `poster.jpg`

## 구성 (문제 → 대표 상호작용 → 사용 후 변화)
| 시간 | 자막 | 화면(실제 제품 녹화) |
|---|---|---|
| 0–4.6s | 산책길의 3초 · “귀엽다!” 다가오는 손 | 사이트 히어로의 거리 다이얼. 20m → 2m로 다가가면 뽀리의 자세가 편안 → 경계 → 회피로 바뀜 |
| 4.6–11.4s | 개마다 다른 거리 · 뽀리는 8m부터 편안해요 | 산책 카드 만들기: 이름 입력, 편한 거리 슬라이더, 조심할 것, 카드 완성 |
| 11.4–13.9s | 보여주기 · 말 대신 화면 한 장 | 보여주기 모드 |
| 13.9–23.4s | 나란히 첫 산책 · 멀리서, 같은 방향으로 | 단계형 나란히 산책 10m → 6m → 4m → 2m, 확인 질문 |
| 23.4–25.5s | 사이 기록 · 10m → 2m | 사이 기록 화면 |
| 25.5–28.6s | 가까워지는 데는 순서가 있어요 | 엔드 카드(로고) |

## 제작 방식과 출처
- 화면은 모두 **실제 제품(체험 모드)을 Playwright로 조작하며 녹화**한 것. 생성 이미지·스톡 영상 없음.
- 컴포지션: `app/film/index.html` (개발 서버에서만 제공, 빌드에 포함 안 됨). 녹화 스크립트: `app/scripts/record-film.mjs`.
- 인코딩: imageio-ffmpeg(ffmpeg 7.0.2) libx264 CRF 22.
- 폰트: Pretendard Variable (SIL OFL 1.1).
- 음악·효과음: **사용하지 않음**. 브랜드 원칙(산책 중 개를 놀라게 하지 않는 조용한 브랜드)과 라이선스 리스크를 함께 고려함. 음악이 필요하면 라이선스가 확인된 트랙을 선택해 따로 입혀야 함.
- 나란히 장면에서는 시연용 자동 수락(2.5초)을 기다리지 않도록 요청 수락 상태를 미리 넣고 녹화함. 영상 속 모든 화면은 ‘체험 모드’ 배지를 표시함.

## 재생성
```bash
cd app && npx vite --port 5173 --host 127.0.0.1 &   # 개발 서버
node scripts/record-film.mjs /tmp/film               # webm 녹화
# 이후 README의 ffmpeg 명령으로 mp4 인코딩(시작 2.9초 잘라냄)
```
