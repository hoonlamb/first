# 댕큐 전략 결정 기록 (Decision Record)

근거: `../01_research/research.md`, `../01_research/sources.md`(S번호), `../02_audit/figma-audit.md`. 사용자 인터뷰 **없음** → 아래 사용자 니즈는 모두 가설.

## 1. 출발 가설의 반박
출발 가설: "우리 개에게 맞는 동네 산책 친구를 만나고, 첫 산책이 다음 산책으로 이어지는 서비스."

| 반박 | 근거 |
|---|---|
| 혼자 쓸 때 가치가 0 — 동네 밀도가 채워지기 전엔 빈 앱 | 매칭형 구조 일반 원리(콜드스타트) |
| 친구를 찾으면 앱을 떠난다 — 성공이 이탈을 만든다 | 매칭 서비스 구조 추론 |
| 반려견 소셜·산책 플랫폼의 실패 사례 | Dogster 커뮤니티 종료(2019, S55), Wag! Chapter 11(2025-07, S53), 도그메이트 회생·인수(S30) |
| 실제 고통은 '친구 부족'이 아니라 '통제 안 되는 접촉' | 견주 89.4%가 산책 중 타인 행동에 불편, 1위 '놀라게 함' 48.7%, '허락 없이 만짐' 39.2%(S05) |
| 산책 사회적 효과는 존재하나 제한적 | Wood 2015 OR 3.10(S71), 일본 연구 약한 효과(S72) |

결론: "만남"을 약속하면 약하다. **"거리"를 약속하면 강하다.**

|---|---|---|---|---|---|

| 포트폴리오 표현력 | 중(흔함) | 상 | 중 | 상 | 하 |

## 3. 최종 방향

**댕큐 — 가까워지는 데는 순서가 있어요.**
우리 개가 편한 '거리'를 말로 보여주는 **산책 카드**, 그 거리를 존중하며 한 걸음씩 좁히는 **나란히 첫 산책**, 좁혀진 거리를 기억하는 **사이 기록**.

| 질문 | 답 |
|---|---|
| 누구의 어떤 순간 | 산책 중 모르는 사람·개가 다가오는 3초. 보호자가 "얘가 좀…"을 설명하지 못하는 순간. (가설) |
| 기존 대안이 부족한 이유 | 옐로 리본 등 표식은 '거절'만 말하고 '어떻게 다가오면 되는지'는 말하지 못한다. 매칭 앱은 만남을 목표로 해서 거리 조절을 건너뛴다. |
| 댕큐의 관점 | **개마다 편한 거리가 있고, 가까워지는 데는 순서가 있다.** 훈련사의 표준 기법인 병행 산책(parallel walk: 먼 거리에서 같은 방향으로 걷다 점점 좁힘)을 누구나 따라 할 수 있는 흐름으로 만든다. |
| 첫 사용 가치 | 1분 안에 우리 개의 '편한 거리'가 적힌 카드가 생기고, 산책길에서 바로 보여줄 수 있다(혼자서도 가치). |
| 재방문 이유 | ① 매 산책 마주침 기록 → 우리 개의 거리가 어떻게 변하는지 보임 ② 나란히 산책은 한 번에 끝나지 않고 "다음엔 8m부터"로 이어짐. |
| 돈을 받을 가치 | 보호자 무료. 수익 후보: 훈련사 동행 소그룹 나란히 산책(회차권), 카드를 받는 돌봄·유치원·훈련 파트너의 연결 수수료. **모두 미검증 가설, 이번 결과물에서 실제 제휴·결제 없음.** |
| 전략 수정 조건 | 인터뷰에서 다수가 '친구 찾기'를 원하고 안전 우려가 낮으면 → A 쪽으로 / 카드 완성률 50% 미만 또는 2주 후 기록 유지 20% 미만이면 → C(장소·시간)로 / 훈련사가 유료 그룹 산책에 참여하면 → D를 수익 코어로 / 같은 동네·시간대 호환 견이 부족하면 → 매칭 제거, 카드+기록만 유지. (수치는 제안 기준, 데이터 아님) |

## 4. 비전 / 이번 제품 / 후속 과제

| 비전 | 이번에 완성할 제품(작동) | 실제 사업 후속 과제(미구현, 포장 금지) |
|---|---|---|

검수 원문: `../05_qa/qa-round1.md`. 반박 검토에서 나온 지적 중 전략과 흐름을 바꾼 것:
