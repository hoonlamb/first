# DJDB 관찰 기록 (참고 전용 — 복제 금지)

확인 경로: 클라우드 환경에서 djdb.kr 직접 접속 불가(네트워크 정책 403). 아래는 **사용자가 제공한 데스크톱 스크린샷 1장(첫 화면)** 에서만 관찰한 내용. 모바일·스크롤 이후·인터랙션은 **미확인**.

## 관찰 (user-shot-01-desktop-hero.webp)
- 타이포: 고대비 볼드 세리프(디도네 계열) 대형 워드마크 "DJDB" + 넓은 자간의 이탤릭 세리프 풀네임 "DaeJangDakBal". 두 크기의 극단적 대비.
- 이미지: 사진 안에 사진이 들어가는 **중첩 프레임(액자 속 액자)** 구성 — 음식(외곽) → 주방(중간) → 사람(중심)으로 좁혀 들어가며 맥락 → 장면 → 인물로 초점 이동.
- 여백: 넓은 흰 여백, 중앙 정렬, 요소 수가 적음.
- 장식: 좌측 상단에 연회색 작은 화살표 글리프들이 흩어져 있음(움직임 여부 미확인).
- 색: 흑백 타이포 + 사진이 유일한 채도(강한 레드).

## 개성을 만드는 원리 (추론)
1. 사진을 '콘텐츠'가 아니라 '구조(프레임)'로 쓴다 — 레이아웃 자체가 이야기의 줌인.
2. 타이포를 로고가 아니라 포스터처럼 크게 쓴다.
3. 절제된 요소 수 + 한 가지 강한 색원.

## 댕큐에 적용할 변환 (복제 아님)
- '중첩 프레임' → 댕큐에서는 **거리(distance)** 를 구조로 쓴다: 두 존재 사이의 간격이 레이아웃과 인터랙션의 뼈대. 사진 액자 대신 '간격의 링/선'.
- 큰 타이포의 태도는 가져오되 세리프 디도네·흑백·레드 팔레트는 쓰지 않는다.

## 사용자에게 요청한 추가 자료
- 데스크톱 스크롤 전체 화면 녹화, 모바일 화면 캡처, 주요 인터랙션(호버/클릭) 녹화.
